# Squadfall — Transição Imediata

**Repositório:** https://github.com/0073dls0093-lgtm/squadfall

Este documento deve ser aplicado pela IA que já está desenvolvendo o jogo. O objetivo é organizar o que já foi feito, registrar tudo no GitHub e deixar o projeto pronto para continuidade por outra IA.

## 1. Ação Principal: Salvar o Estado Atual no GitHub

Não refaça o jogo. Faça uma inspeção objetiva do estado atual e coloque no repositório tudo o que já for necessário para outra IA continuar:

Crie ou atualize na raiz do projeto. Registre somente fatos confirmados.

Se o projeto tiver um documento de design, diferencie o que está planejado do que realmente foi implementado. Não marque uma funcionalidade como concluída apenas porque ela aparece no GDD.

## 2. Documentação Mínima

Verifique se existe. Se não existir, crie um arquivo simples com:

- Tecnologias utilizadas
- Como instalar
- Como executar
- Como testar
- Estrutura básica do projeto
- Estado atual e limitações

Crie se ainda não existir, contendo as regras de continuidade, economia e preservação do trabalho.

## 3. Checkpoint no GitHub

Depois de organizar os arquivos:

1. Verifique se os arquivos essenciais estão completos
2. Execute somente verificações objetivas e necessárias
3. Atualize
4. Faça um commit descritivo
5. Envie o commit ao repositório, se houver autorização e acesso
6. Confirme claramente se o push foi realizado

Se não puder fazer push, informe exatamente isso e deixe os arquivos prontos para envio manual. Não diga que o GitHub foi atualizado se o push não tiver ocorrido.

## 4. Economia de Créditos

Trabalhe de forma econômica e direta:

- Não fique revisando repetidamente o que já foi feito
- Não reanalise o projeto inteiro sem motivo
- Não repita testes já executados e registrados
- Não fique "rodando em círculos" sobre funcionalidades validadas
- Não refaça código que já funciona
- Não gere PDF, imagens, vídeos ou relatórios extras
- Não me envie relatórios longos a cada pequena ação
- Não descreva a mesma conclusão várias vezes
- Leia somente os arquivos necessários
- Faça uma verificação objetiva e suficiente
- Depois de salvar o checkpoint, encerre esta tarefa

Economizar não significa ignorar um erro real. Se encontrar uma falha concreta, corrija-a e teste somente o impacto necessário.

## 5. Novas Ideias

Se identificar uma melhoria, registre-a de modo curto com benefício, custo, risco e status. Não implemente automaticamente mudanças que alterem o escopo, a arquitetura ou as decisões do usuário.

## Resultado Esperado

A IA atual deve deixar o repositório com o código existente salvo, documentação mínima, contexto sem contradições, histórico atualizado e próxima tarefa clara para a próxima IA.
